# Victor's Cloud & Software Engineering Portfolio
A personal portfolio website for a Level 3 Computing student interested in cloud computing, cyber security and software engineering.

## Includes
- About me section
- AWS learning and certification information
- Links to portfolio projects
- Responsive HTML and CSS design
- GitHub Pages ready

## Run locally
Open `index.html` in a web browser.

## Publish
Upload the files to a GitHub repository, then use Settings → Pages → Deploy from a branch → main → /(root).
