CareCircle

Building

A shared space for families coordinating care for someone: medications, appointments and notes, with invitations and member roles. Each family's data is protected by database row-level security, checked by 24 automated tests that run the real schema in PostgreSQL. The tests found and fixed a real gap.

React, Vite, Supabase (PostgreSQL, Auth, Edge Functions), PGlite, GitHub Actions, installable as an app
