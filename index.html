Kubernetes GitOps Platform

Working

A production-style Kubernetes platform managed entirely from Git with ArgoCD. It runs my deadline app with images that are scanned and signed in CI, and the cluster refuses anything unsigned, running as root or without resource limits. HTTPS comes through the Gateway API, only the API can reach the database, the API scales itself under load, and Grafana dashboards and alerts watch it all. Every push builds a fresh cluster in GitHub Actions and tries to break it.

Kubernetes, ArgoCD, Helm, Envoy Gateway, cert-manager, Kyverno, Cosign, Sealed Secrets, Prometheus, Grafana, k6, GitHub Actions

Due: deadline tracker

Working

A full-stack app (React, FastAPI, PostgreSQL) that tracks coursework deadlines by module, labels what's overdue or due soon, and gives each user a private calendar link so deadlines appear in their phone's calendar. Passwords are hashed with Argon2, logins use JWTs, and a dedicated set of tests proves no user can see another user's data. The AWS setup is written in Terraform with a budget alert and keyless deploys from GitHub.

React, TypeScript, Python, FastAPI, SQLAlchemy, PostgreSQL, Docker, Terraform, 54 automated tests in GitHub Actions
